# Modelos de importação

Esta pasta conterá modelos CSV/XLSX sem dados reais. Cada modelo terá:

- versão do contrato;
- ano-base;
- campos obrigatórios e opcionais;
- tipos e domínios permitidos;
- chave de unicidade;
- totais de controle;
- exemplos fictícios;
- regra de rejeição.

A primeira versão deverá contemplar ciclos PNP, faixas de renda, indicadores institucionais, parâmetros dos campi e envelopes orçamentários.
